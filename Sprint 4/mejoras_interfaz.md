# Mejoras de Interfaz y Experiencia de Usuario – ZIGNA

Durante esta actualización se realizaron mejoras visuales y de interacción dentro del sistema ZIGNA, enfocadas en brindar una experiencia más clara, intuitiva y agradable para el usuario, sin modificar la estructura principal del proyecto.

## Mejoras implementadas

- Se mejoró la presentación visual del progreso del usuario.
- Se realizaron correcciones visuales en formularios, evaluaciones y módulos interactivos.
- Se agregó una lista desplegable en la sección “Módulos” para simplificar la navegación y reducir la cantidad de elementos visibles dentro del sistema.
- Se agregó un botón “Ir al progreso” al finalizar las evaluaciones para mejorar el flujo de navegación del usuario.
- Se unificó la interfaz de navegación agregando la opción “Cerrar sesión” en la pantalla de progreso, manteniendo consistencia visual con el resto del sistema.

## Objetivo de las mejoras

El propósito de estas modificaciones fue mejorar la experiencia del usuario dentro de la plataforma, haciendo que la interacción con el sistema fuera más clara, organizada y visualmente atractiva.

# Validación Externa del Sistema – ZIGNA

| Proyecto / Equipo | ZIGNA – Chicas superpoderosas |
| Docente externo | Niria Gonzalez Ortiz |
| Fecha | 21 de mayo del 2026 |
| Pregunta 1 | ¿Qué parte del sistema considera más clara o rescatable? |
| Respuesta | El docente destacó que visualmente el sistema es agradable y organizado. Consideró como punto más rescatable la interfaz visual y sugirió agregar una breve introducción en la pantalla principal para explicar el propósito de la plataforma y el contexto relacionado con la Lengua de Señas Mexicana. |
| Pregunta 2 | ¿Qué aspecto debería mejorar para ser más útil, entendible o funcional? |
| Respuesta | El docente señaló que al finalizar una evaluación el usuario queda al final de la página y puede perderse sin saber cuál es el siguiente paso. Sugirió redirigir automáticamente al usuario hacia el inicio, módulos o progreso para mejorar el flujo de navegación y experiencia de usuario. |
| Pregunta 3 | Si solo pudiera solicitar un cambio concreto, ¿cuál sería? |
| Respuesta | El docente recomendó mejorar el flujo posterior a las evaluaciones, implementar efectos visuales interactivos como hover o zoom, y revisar aspectos básicos de seguridad relacionados con acceso mediante URL y visualización de archivos internos. |
| Impacto | Funcionalidad / Usabilidad / Seguridad básica / Visual |
| Mejora solicitada | Implementar redirección automática después de evaluaciones, agregar introducción informativa en pantalla principal, incorporar efectos visuales interactivos y fortalecer la protección básica de rutas y directorios del sistema. |
